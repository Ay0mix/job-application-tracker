# Job Application Tracker

Open `index.html` in a browser. Works offline, no server needed. Built with HTML, CSS and JavaScript.

## Features
- Dashboard: stats (incl. progress rate), colour-coded pipeline, applications sent per week, upcoming deadlines
- "Worth chasing" list: applications stuck at *Applied* for 14+ days
- Search / filter / sort applications (newest, deadline, furthest stage, A–Z)
- Add / edit / delete applications (click any row to edit; press **N** to add; **Esc** closes the form)
- Moving an application to *Applied* or later fills in today's date if none was set
- Deadlines only show for opportunities that are still open
- Data saved in the browser (localStorage)
- CSV export/import. Works with files opened and saved in Excel, and with descriptions that have commas or line breaks. Import lets you replace or add to your list.
- Responsive desktop/mobile layout

Tip: export a CSV now and then as a backup. Clearing your browser data deletes the saved list.
